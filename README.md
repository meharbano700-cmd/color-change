# Swift Lab Technologies

A plain Vite + React (JavaScript) website. No TypeScript, no TanStack Start, no Lovable tooling.

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

For the contact form (Gmail-based, via `server.js`), see `CONTACT-FORM-SETUP.md`.
